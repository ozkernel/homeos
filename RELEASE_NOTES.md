# HomeOS v1.0.0 — Release notes

Welcome to HomeOS v1.0.0, a self-hosted dashboard for your homelab.

## Highlights

- Monitor Unraid, Proxmox VE and Proxmox Backup Server.
- Connect your media applications, including Plex, Jellyfin, Sonarr, Radarr, Lidarr and Bazarr.
- Track downloads with qBittorrent and SABnzbd.
- Use calendars, notes, files, tasks and app shortcuts.
- Personalise your dashboard with themes, widgets and layouts.
- Try Demo Mode before connecting your own services.

## Install

HomeOS v1.0.0 uses the Linux amd64 Docker image:

`ghcr.io/ozkernel/homeos:1.0.0`

See [Installation](INSTALLATION.md) for Docker Compose and Unraid instructions.
