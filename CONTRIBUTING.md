# Contributing to HomeOS

Thanks for helping make HomeOS better.

HomeOS is an **AI-assisted project** whose maintainer is learning software development. Constructive explanations, bug reports, documentation fixes and suggestions are appreciated. Criticism of a technical problem is welcome; personal attacks are not.

## What this repository accepts

This repository contains **public installation and documentation files**, not the HomeOS application source. You may propose improvements to docs, template settings and support guidance through GitHub Issues or pull requests. Contributions to this repository are accepted under its [MIT License](LICENSE).

For a new feature or integration, open an **Idea / feature request** issue. For an application-code fix, open a **Bug report** issue explaining the problem first. Private source access is **not automatically available**, and you should never ask for a production API key or upload confidential code.

## Before submitting a documentation PR

- Explain the problem and the intended result.
- Do not include secrets, internal addresses or private user data.
- Confirm the README, install commands and Docker/Unraid settings match each other.
- Note any change affecting default network access or persistent volumes.

Contributors do not get control over official HomeOS releases. Final publication remains with the project maintainer.

Read the [Code of Conduct](CODE_OF_CONDUCT.md) and [Security policy](SECURITY.md).
