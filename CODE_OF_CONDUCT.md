# HomeOS community code of conduct

Everyone is welcome to discuss HomeOS, including beginners, experienced developers, and people who use AI-assisted development.

Please offer **specific, respectful, constructive** feedback. Report bugs with evidence, explain proposed fixes clearly, and be patient with people learning new tools.

Harassment, threats, personal attacks, discriminatory remarks, repeated ridicule and demands for private code or credentials are not acceptable.

The project maintainer may moderate or close disruptive discussions and may restrict participation. Technical criticism and responsible security reports remain welcome.

For sensitive security concerns, use the [private vulnerability reporting guidance](SECURITY.md). For community conduct concerns, contact the maintainer through GitHub without posting another person's private information.
