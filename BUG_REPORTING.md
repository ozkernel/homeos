# Report a bug

First check [Support](SUPPORT.md) and [Installation](INSTALLATION.md). Then choose [New issue](https://github.com/ozkernel/homeos/issues/new/choose) and select the bug report form.

Include the HomeOS version, OS/Docker environment, affected integration, expected/actual behaviour, and reproducible steps. Only include screenshots and logs **after redacting private information**.

For feature ideas, choose **Idea / feature request** on the same [New issue](https://github.com/ozkernel/homeos/issues/new/choose) page.

For security bugs, follow [SECURITY.md](SECURITY.md), not public issues.
