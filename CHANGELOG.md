# HomeOS changelog

## v1.0.0 — First release

HomeOS v1.0.0 includes:

- **Infrastructure:** Unraid, Proxmox VE and Proxmox Backup Server dashboards.
- **Media:** Plex, Jellyfin, Seerr, Radarr, Sonarr, Lidarr, Bazarr, Prowlarr, qBittorrent and SABnzbd.
- **Network:** UniFi and AdGuard Home.
- **Workspace:** Calendars, notes, files, tasks, wiki and app shortcuts.
- **Personalisation:** Dashboard widgets, themes, layouts and accounts.
- **Calendar:** Lidarr album releases as an optional source.
- **Monitoring:** Smoother resource graphs and CPU/RAM usage bars.

See [Installation](INSTALLATION.md), [Release notes](RELEASE_NOTES.md) and [GitHub Releases](https://github.com/ozkernel/homeos/releases).
